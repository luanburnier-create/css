Como Dominei o Flexbox no CSS

O Flexbox revolucionou a forma como criamos layouts na web. Com propriedades simples como flex-direction e align-self, conseguimos organizar elementos horizontalmente de forma responsiva, elegante e sem quebrar a estrutura da página.

Alinhamentos Independentes com Align-Self

Enquanto o container dita as regras gerais de alinhamento para todos os filhos através do align-items, a propriedade align-self dá superpoderes para um único elemento quebrar a regra do grupo e se posicionar de forma única.
